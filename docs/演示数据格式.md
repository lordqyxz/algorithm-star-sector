# 演示数据格式（Trace Format）v1

沙盘推演采用"数据与算法分离"的三层架构，与游戏王国共用同一套语义色与组件语言：

```
算法生成器（纯函数，yield 事件流）
  → recordTrace 折叠为 Trace（可 JSON 序列化的演示数据）
    → TracePlayer（唯一渲染器）渲染每一拍
```

## 核心类型（src/engine/trace.ts）

- `Trace = { eyebrow, description, steps: TraceStep[] }` —— 一节沙盘的全部数据，`label` 均为 `string | number`，可整体存为 JSON。
- `TraceStep`（一拍）：`title / tab? / question? / formula / formulaHint? / scenes / legend? / moves? / judge? / stability? / metrics / equation? / invariant? / pseudocode? / note? / conclusion / prediction?`。
- `Scene`（该拍的视觉，可多个）：`array`（cells+pointers+regions）/ `tree`（按层，null 为空位）/ `buckets` / `matrix` / `bars` / `shapes`（通用 SVG：line/circle/rect/text/path）。
- 语义色 `Tone` 全站统一：`focus=当前处理、key=暂存键、pivot=主元/分界、sorted=已确定、target=目标/候选、muted=已排除`。

## 事件流（src/engine/events.ts）

生成器逐拍 `yield`：`scene`（声明/替换场景）、`cells` / `cell` / `pointers` / `regions` / `swap`（数组场景增量更新）、`bucket`、`bars`、`metrics`（实时计数器）、`legend`、`message`（本拍的叙事与公式）、`step`（封存快照）。
`recordTrace(eyebrow, description, generator)` 折叠成 `Trace`；未封存的尾拍自动收尾。

## 沙盘文件模板

```tsx
import { TracePlayer } from '@/engine/TracePlayer'
import { recordTrace, tokenize, type TraceEvent } from '@/engine/events'

function* runXxx(input: XxxExample): Generator<TraceEvent> { /* 真实执行算法，每拍 yield 事件 */ }

const buildXxxTrace = (example: XxxExample) => recordTrace('SANDBOX NN · XXX', '一句话简介', runXxx(example))

export function XxxLesson() {
  const [exampleId, setExampleId] = useState(examples[0].id)
  const example = examples.find(e => e.id === exampleId) ?? examples[0]
  const trace = buildXxxTrace(example)
  const playback = useLessonPlayback(trace.steps.length)
  return <LessonShell
    eyebrow={trace.eyebrow} title={trace.steps[playback.step].title} description={trace.description}
    steps={trace.steps.map(s => s.tab ?? '推演')} step={playback.step} onStepChange={playback.setStep}
    playing={playback.playing} onTogglePlaying={playback.togglePlaying} onReplay={playback.replay}
    speed={playback.speed} onCycleSpeed={playback.cycleSpeed}
    complexity={xxxComplexity}
    examplePicker={<ExamplePicker examples={examples} value={exampleId} onChange={id => { playback.reset(); setExampleId(id) }} />}>
    <TracePlayer trace={trace} step={playback.step} />
    <DesignNotes insight={xxxInsight} />
  </LessonShell>
}
```

## 硬约束

- 生成器必须是纯函数：确定性（随机需固定种子）、不可变输入、无渲染期副作用。
- 每拍一个因果：一次比较、一次移动或一次结论；`formula` 中的数字必须能从该拍 scenes 里指出来。
- 排序沙盘：重复值用 `tokenize` 获得身份（4A/4B），并在 `stability` 中呈现稳定性证据。
- `metrics` 至少含两个实时计数器；`pseudocode.active` 必须与该拍真实执行的行一致。
- 每沙盘 ≥2 个 `prediction`，位于概念转折拍。
- 完整样板见 `src/lessons/insertion-sort.tsx`。
