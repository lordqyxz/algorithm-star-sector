## 已有可信部分与测试限制

- sorting 的主要排序终值实际由算法计算；测试将结果与原生数值排序比较，并检查元素身份与稳定排序的重复值顺序。这些终值检查有价值，但不能覆盖中间帧身份或 tournament 方法错误。
- replacement selection 使用真实活跃最小堆、冻结集合及单调归并段；最优归并代价的测试穷举所有两两合并顺序，是独立参考，值得保留。
- algorithms 中 quickselect、最短点对、Strassen、4点 FFT、Johnson、0/1背包、矩阵链、LCS、双机子集 DP 有实际计算，不应笼统称为硬编码答案。问题主要在部分前提、命名和缺乏可观察中间状态。
- optimization 中集合覆盖、极大匹配顶点覆盖、修剪列表子集和、利润缩放背包有实际实现。近似保证测试除检查数值界外，还必须从最终所选对象独立验证可行性和目标值。
- graphs 的 Floyd、MST、增广流计算实际存在；需要检查表示与算法一致，不能将终值正确等同于过程正确。
- structures 初始测试重点是帧形状、有限计数和确定性，无法识别上述伪指针、伪内存错误和缺失合并。模型级命令测试比增加 frame 数量断言更重要。
- 固定两个正例只能证明两个实例；至少为每个关键规则加入一个会使错误实现失败的反例。具体例子包括非法括号、伙伴不对齐、队列环绕、不可达顶点、不可行容量和重复键。

## 结论适用边界

本报告关闭的是列出的具体缺陷，不宣称任意输入均正确，也不以固定样例通过代替完整课程覆盖。最终验收同时需要：算法名称匹配执行方法、输入满足证明前提、结果可由独立参考复算、每个重要状态可观察且可回退、图示与数值来自同一状态。完整课程覆盖另与 `CURRICULUM.md` 对照；父任务的目录契约测试与浏览器检查负责跨模块集成。
