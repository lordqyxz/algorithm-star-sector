## 2. 什么才算覆盖

每个下文编号是一项可审计要求，可以共享场景，但必须有自己的输入、操作、学习检查和证据。菜单、标题、单选题或一段介绍不能单独算“算法已实现”。同一关中展示多个名字，也不能自动覆盖多个算法。

| 状态 | 必须具备的证据 | 允许的表述 |
| --- | --- | --- |
| P：规划 | 来源、任务目标、范围已记录 | 已纳入课程规划 |
| E：机制演示 | 可操作的小实例；真实状态变化；至少一个预测和迁移检查 | 演示了这个机制，注明实例范围 |
| I：算法实现 | 对声明输入域执行完整算法；状态和结果由算法生成；边界处理与独立基准核验 | 已实现指定算法及输入域 |
| T：理论覆盖 | 定义、条件、论证链、反例/边界和迁移问题齐备 | 覆盖了指定理论目标 |
| V：综合验收 | E/I/T 中该主题所需证据通过；来源追踪、操作路径和测试可复查 | 在明确范围内完成该主题 |

**本文件初版所有行仅为 P；实际实现状态见 [COVERAGE-AUDIT.md](./COVERAGE-AUDIT.md)，不能从本规划表直接授予 E/I/T/V。** 实现审计按每行记录 `missionId → 文件/函数 → 声明输入域 → E/I/T → 测试证据 → 缺口`。一个固定预录轨迹只能是 E；若根据新输入重新计算并通过基准检查，才可进入 I。理论主题不强求伪装成数值算法，但必须达到 T，不能只靠选中正确术语过关。

每项学习过程统一为：预测下一步 → 操作真实对象 → 观察一次因果变化 → 指出不变量/公式中的数值来源 → 换输入解释。状态由确定性模拟和命令日志持有，随机算法记录种子；PixiJS 承载游戏，站点外壳不持有算法状态。按 [动画绘制方法论](./动画绘制方法论.md) 的行为原则设计；其中旧课件组件的历史描述不改变 AGENTS.md 禁止恢复课件体系的要求。

## 3. 去重主题与可玩任务

矩阵中的“验收重点”含本项目采用的具体化方案。对于大纲只给出类别的地方，所选算法是可核验的代表，不表示原文点名该算法，也不表示覆盖该类别的一切变体。

其中 F10 的额外研究阅读、D07 的确定性最坏线性选择、R04 的 Johnson 扩展、P07 的 LCS 等是教学设计建议，不是新的官方具名必修项；完整删除变体、任意输入接口等也应与声明实现范围区分。课程并集要求不能机械等同于全部 128 行的所有扩展条件。

## 5. 算法正确性与可玩规模的交付约束

“可玩”不要求大规模。建议主路径使用 6–12 个元素、4–8 个顶点、最多 8 个对象的指数搜索；FFT 用 8/16 点，Strassen 用 2×2/4×4，15 迷保留真实 4×4 但从目标经少量合法步打乱。规模上限、支持输入域、预算耗尽行为都应在任务内说明；不得因此把真实问题悄悄换成另一个问题。

| 类别 | 必要独立核验 | 常见不能通过的替代 |
| --- | --- | --- |
| 结构/排序/查找 | 操作后结构不变量；与朴素模型对照；重复值、空/单元素、首尾 | 只有最终答案或预写每一步 |
| 树的维护 | 每次操作后有序性、父子链接、颜色/高度/容量不变量 | 静态展示一棵合法树就说完整支持维护 |
| 图 | 小图穷举/独立参考；不可达、环、重复权；流守恒及残量反边 | 所有路径问题共用一个 BFS 动画 |
| 分治/DP | 暴力小实例对照；边界与解恢复；公式数值来自当前状态 | 只有填表结果，没有递推过程 |
| 搜索/分枝限界 | 与无剪枝穷举最优值一致；无解与预算不足分开 | 固定解或看起来合理但不安全的剪枝 |
| 随机 | 固定种子可重放；每次输出的有效性；概率/期望的独立论证 | 几次成功就声称零错误/保证期望 |
| 近似 | 可行性；小实例精确最优对照；保证前提及理论比值证明 | 只显示比最优差多少就说有近似保证 |
| LP/最小费用流 | 标准型/约束/流守恒；独立极点或小流枚举；退化/不可行实例 | 只画可行域或只跑没有逆边的增广 |
| 启发式/神经网络 | 每次目标重算、可行性检查；固定种子；梯度数值检查 | 自动递减的漂亮损失曲线或“最优”标签 |
| 理论 | 概念、量词、前提、完整论证、边界反例和新实例 | 术语卡片或单次正确选择 |

必须特别核对的非等价项：次优树≠最优 BST；树形选择≠堆排序；普通矩阵分块≠Strassen；单源最短路≠最小生成树；多段图≠全点对；贪心流水调度≠流水 DP；回溯≠分枝限界；概率数值估计≠有界错误决策；启发式≠有保证近似；8 迷≠15 迷。

## 6. 审计登记格式与发布口径

逐项审计使用下表格式，复用同一场景时仍逐项填写。状态清单可由实现团队另建或在此表追加，不能只统计任务标题数量。

| 主题 ID | missionId / 文件函数 | 支持输入域与明确限制 | E/I/T 证据 | 独立核验 | 状态 / 未覆盖内容 |
