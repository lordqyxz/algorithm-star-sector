- 原三种指定策略样板保留；同一挑战实例的提示暴露与完成跨重开、切换、刷新保留。旧版独立记录与新版 V2 分开。
- 原 130 项任务、53 份理论说明、课堂来源与旧进度保留。手机界面不在本轮范围。

## 规则、公式与存档

冻结依赖安装、类型检查、151 项测试和生产构建通过。无新增依赖；生产构建仍提示主资源大于 500 kB，不影响构建成功。

独立基准覆盖路径、子集、割与目标判定；重点检查提前标记后数值修复不能恢复 Dijkstra 策略证书、错误 DP 值的传播标记、部分增广与反向撤流、源图 NO/空目标议题集 YES、已创建空名单议题 NO、单集合映射失真与整实例存在性判定的区别。公式与读数经严格 KaTeX 解析，预览不改变权威状态或实际成本。

存档检查覆盖重放、游标、固定 A 的身份、回退后分歧保留原未来、换输入从初态重算、无效提交不进入命令历史、损坏原始存档先备份再覆盖，以及浏览器存储失败时当前会话可继续使用。

## 浏览器与视觉

使用独立浏览器会话，不操作个人浏览器记录。桌面宽度 1280 / 1440，高度 1100；完整页面截图确认超出首屏的依据、公式和历史区域可访问。

真实鼠标检查两种宽度均通过：节点、正反边、任意 DP 格、上一行依赖、物品、教授名单与源顶点见证分别命中；选择只预览，提交才改变状态。另检查分歧、固定/交换、输入草稿、左右键、重开保留未来、Escape、减少运动和销毁后原生控件清理。

截图复核修复两类自动检查不足以替代的问题：归约源图共线造成长边覆盖短边的命中，以及最大流反向长标签覆盖原边流量。前者改为非退化源图并增加边段几何测试；后者扩大标签避让范围、为远位标签加引线。

审计器另修复 Pixi 遮罩的空全局边界问题：使用遮罩局部边界转换到世界坐标，交集宽高不能为负；新增两项回归测试，避免将被遮挡文字静默排除。旧审计器的零问题结果不作为本轮最终视觉依据。

修正审计器后先发现 15 个旧关卡的长标签、表格与过渡问题，已通过公共测量与布局规则修复。受影响子集在两宽各检查 422 帧，再执行上述全目录生产审计。栈/队列重排与内存压缩还各连续检查 20 个动画帧（约 0–300ms），无文字相交。

危险的移动先按扫过区域检测；可能撞卡片或越遮罩时直接就位，保留对象身份和方向箭头，安全通道继续动画。多行数值、说明、分组和输出使用与实际字体一致的高度；矩阵按真实数字宽度分页。矩阵双轴同时溢出时逐列再逐行访问，测试用 10×20 与 7×11 表确认每个单元格可达，尾页前后严格可逆。

展开依据置于图下宽面板；边权/残量标签与真实边调用相同动作。当前与一个 A 对照的替换规则明确显示，不将不同输入的成本差解释为策略快慢。
